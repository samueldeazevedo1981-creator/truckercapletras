TRUCKER CAP LETRAS V1.3 — SEM ACERVO EMBUTIDO
PACOTE LEVE PARA GITHUB + VERCEL

1. Extraia o ZIP.
2. Envie TODOS os arquivos e pastas ao GitHub.
3. Importe o repositório na Vercel.

Framework: Other
Root Directory: ./ (a pasta com package.json)
Node.js: 24.x
Install Command: npm ci --ignore-scripts
Build Command: npm run build
Output Directory: public
Variáveis de ambiente: nenhuma

NÃO escolha public como Root Directory.

O cliente cria seu repertório pelo botão Nova música ou importa TXT, ChordPro e PDF.
Arquivos ZIP e RAR devem ser extraídos antes de importar os documentos.

Para uso off-line: primeiro abra conectado, aguarde Pronto para uso off-line, importe os documentos e aguarde a conclusão. Depois teste a reabertura em modo avião.

O pacote mantém ícone, setlists, leitor PDF, rolagem e configuração de pedal.
Leia README.md para os detalhes de publicação e instalação.
